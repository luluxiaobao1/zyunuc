# 访问控制原型（结算单元 / 资源组管理）

克隆 360智汇云控制台「访问控制」下两个列表页的静态高保真原型：

- 结算单元（`console.zyun.qihoo.net/accessmanage/settlementunit`）
- 资源组管理（`console.zyun.qihoo.net/accessmanage/resourcegroup`）

## 技术栈

纯静态 HTML / CSS / 原生 JS，无框架、无构建、无外部依赖。直接双击 [`index.html`](index.html) 即可在浏览器打开。

## 文件结构

```
index.html          页面骨架：顶栏 + 图标栏 + 二级菜单 + 内容区（两个视图）+ 标签抽屉 / 批量弹框
styles.css          列表页专属样式（搜索框、下拉、表格、分页器、悬浮按钮、抽屉、弹框、批量条）
app.js              假数据生成 + 通用列表控制器 + 视图切换 + 标签管理 / 批量设置
shared/base.css     设计系统变量与三栏外壳公共样式
screenshots/        视觉核对截图
```

## 设计规范

样式取自 `zyun-style-design` skill 的 360智汇云设计系统，关键变量集中在 [`shared/base.css`](shared/base.css:1) 的 `:root`：

| 项 | 值 |
| --- | --- |
| 主色 / 链接色 | `#0066FF` |
| 图标栏背景 | `#2e8cff` |
| 文字 主 / 次 / 辅助 | `#202020` / `#666666` / `#8C9AAE` |
| 边框 | `#D8E0E8`、`#E6E6E6` |
| 背景 / 表头底 | `#F0F5F7` / `#F8F9FA` |
| 字号 / 行高 | 14px / 1.5 |
| 圆角 | 小 2px、中 4px |
| 布局 | 顶栏 50px + 图标栏 50px + 菜单栏 200px + 自适应内容区 |
| 标签抽屉宽度 | `75vw`（约页面宽度 3/4），`min-width: 480px`、`max-width: 1200px` |

间距统一走 4px 栅格（4 / 8 / 12 / 16 / 20 / 32）。抽屉加宽后，标签名列固定 320px、新增输入框限宽 360px，避免行内元素被横向拉散。

## 标签设计

两类标签采用同一套数据模型（标签实体 + 数据行单值外键），只在文案与筛选控件上有差异：

| | 结算单元 | 资源组 |
| --- | --- | --- |
| 字段 | `tagId`（单值，可为 `null`） | `tagId`（单值，可为 `null`） |
| 关系 | 一个结算单元对应一个标签，一个标签可对应多个结算单元 | 一个资源组对应一个标签，一个标签可对应多个资源组 |
| 取值范围 | [`unitTags`](app.js:27) 初始 10 个，可增删改 | [`rgTags`](app.js:1) 初始 19 个，可增删改 |
| 表格渲染 | 单个 chip，无标签显示 `-` | 单个 chip，无标签显示 `-` |
| 筛选控件 | 普通下拉，选项全量平铺 | 可搜索下拉，输入即过滤，带清除按钮 |

- 结算单元标签表达「归属口径」，如 `集团外`、`集团内非中台`、`中台内非智汇云`、`智汇云自用` 等，由 [`unitTagOf()`](app.js:1) 依据名称与组织架构关键词推断，无法命中时按枚举轮转兜底
- 资源组标签表达「用途 / 环境 / 技术栈」，如 `AI大模型`、`大数据`、`容器`、`中间件`、`生产`、`灰度` 等，由 [`rgTagOf()`](app.js:1) 依据资源组名称关键词匹配，无法命中时按枚举轮转兜底
- 标签建成可维护的实体：`unitTags` / `rgTags` 存 `{ id, name }`，数据行只存 `tagId`，改名不需要回写数据行；`findXxxTag()`、`xxxTagName()`、`xxxTagIdOf()`、`xxxTagCount()` 承担 id ↔ 名称的换算与关联计数
- 筛选下拉的选项直接读标签实体（[`createList()`](app.js:148) 的 `tagOptions` 支持传函数），新增或移除标签后下拉自动同步，无需改动筛选代码

## 数据说明

[`app.js`](app.js:1) 中两份假数据的首 10 条均为截图里的真实内容：

- 结算单元 262 条：按「事业群 → 二级部门 → 小组」组合枚举补足，组合用尽后追加轮次后缀，保证名称不重复
- 资源组 186 条：按「前缀 → 用途后缀」组合生成，资源组ID 从 6543 递减，所属结算单元取自结算单元数据

## 交互

两个列表共用 [`createList()`](app.js:148) 控制器：

- 搜索：结算单元按名称模糊匹配；资源组按名称或资源组ID匹配。回车或点击放大镜触发，结果重置到第 1 页
- 结算单元筛选（仅资源组页）：下拉选项由资源组数据去重生成，与搜索条件叠加生效
- 标签筛选：结算单元页用普通下拉；资源组页用可搜索下拉，聚焦展开全部选项、输入按关键字过滤、选中后显示清除按钮。与搜索、结算单元筛选三者叠加生效，任一条件变化都重置到第 1 页
- 分页：页码点击、上下页、省略号折叠、首末页常显
- 每页条数：10 / 20 / 50 / 100
- 跳至：输入页码回车跳转，越界自动收敛到有效范围
- 侧边菜单：点击切换高亮、页面标题与内容区视图

控制器提供 `afterRender(pageRows)` 钩子（[`app.js:279`](app.js:279)），结算单元页借此在每次渲染后同步表头全选框状态。

### 标签管理抽屉

结算单元与资源组两个抽屉共用同一套 DOM、样式与逻辑，差异收敛进 [`SCOPES`](app.js:562) 配置对象（实体文案、提示、`tags()` / `find` / `count` / 增删改 / 批量赋值 / 清选 / 刷新），入口切换时动态填充标题、提示与表头文案。

- 入口：结算单元工具栏「标签管理」按钮；资源组工具栏「标签管理」按钮（`openDrawer()` 按 `SCOPES.unit` / `SCOPES.rg` 打开对应抽屉），右侧抽屉滑出，点击遮罩或右上角关闭
- 列表每行展示标签名称、关联实体数（结算单元 / 资源组）、`编辑 | 移除` 操作，由 [`renderTagList()`](app.js:527) 渲染
- 添加：顶部输入框 + 「添加」按钮，成功后清空输入并 toast 提示
- 编辑：行内切换为输入框，自动聚焦并全选原文本，操作列变为 `保存 | 取消`
- 移除：标签已被关联时先弹二次确认，说明将清空这些实体（结算单元 / 资源组）的标签；确认后级联把对应 `tagId` 置为 `null`
- 校验：名称必填、不超过 12 个字符、同名去重，错误信息就地展示
- 任一变更后 [`refreshAfterTagChange()`](app.js:551) 会同时刷新抽屉列表、筛选下拉与表格；若当前筛选项被移除，下拉回落到「全部」

### 批量设置标签

结算单元与资源组两页的批量弹框共用一套逻辑，同样由 [`SCOPES`](app.js:562) 驱动文案与赋值行为。

- 选择：表头全选框控制当前页，行勾选框单选，部分选中时全选框为 indeterminate 态；选中行整行高亮
- 批量操作条：仅在有选中项时出现，显示「已选择 N 个结算单元 / 资源组」，含「批量设置标签」与「取消选择」
- 弹框：展示待处理数量、标签下拉、「清空标签」勾选项；勾选清空后下拉置灰，二者互斥
- 校验：既未选标签也未勾选清空时，确定按钮就地报错
- 提交后按选中集合批量写入或清空 `tagId`，清空选择并 toast 反馈处理数量
